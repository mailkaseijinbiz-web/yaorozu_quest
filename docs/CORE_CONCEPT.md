# 八百万クエスト — コアコンセプト

> 本ドキュメントは `docs/SPEC.md` §1（概要・コンセプト）から、プロダクトの中核思想を抽出・要約したものである。詳細な仕様は SPEC.md を参照。

---

## ひとことで言うと

**現実の神社・寺院・史跡を巡り、その場に宿る「八百万神（AI）」と対話しながらクエストを遂行し、「徳」を積んで世界を幸福にしていく、位置情報連動型の巡礼ゲーム。**

---

## 4つの核

### 1. 場 × 神 × 徳 の三位一体

| 要素 | 英名 | 役割 |
|---|---|---|
| **場** | Spot | 現実世界のスポット。GPS座標から自動生成される |
| **八百万神** | Agent | 各スポットに宿るAIキャラクター。対話相手であり、クエストの出題者 |
| **徳** | Toku | 通貨/経験値。クエスト遂行で獲得し、称号・レベル・バッジが成長する |

### 2. 設計哲学 — 「世界の幸福」を最大化する

コンセプトを貫く中心の式。単なる表示指標ではなく、**ゲームメカニクスの根幹**である。

```
世界の幸福 = 場の活気 + 人間の覚り
          = (enjoyments − issues) + totalToku
```

- **場の活気（spotVitality）** = その場の「楽しみ方（価値）」の数 − 「課題」の数
- **人間の覚り（enlightenment）** = ユーザーの累積徳（totalToku）

ユーザーが価値（enjoyments）を増やし課題（issues）を解決すると場の活気が上がり、徳を積むと人間の覚りが上がる。

### 3. 神の戦略的役割 — 「価値・課題のループを閉じる」

すべての神は総本尊 **アマテラス（大日 / DAINICHI）** の人格（Identity）を継承し、3つの働きを通じて世界の幸福を高める。

| 働き | 内容 | メカニクス |
|---|---|---|
| **価値の増幅** | enjoyments を増やす | UGC投稿で「楽しみ方」が育つ |
| **課題の解決** | issues を減らす | `resolveIssue` タスク（最高報酬 60 徳） |
| **試練を課す** | 徳を授ける | クエスト遂行で人間の覚りを高める |

価値を1つ増やし課題を1つ解決すると活気は **net +2**（issues −1 + enjoyments +1）。この「ループを閉じる」ことが神の戦略の中核であり、課題解決が最高報酬に設定されている理由である。

### 4. クエストの構造 — 神の3つの働きの体現

クエストは 3〜5 個のタスクで構成され、必ず以下を1つずつ含む三段構造になっている。

```
👁️ 情報収集 (sense) → 🧠 理解判断 (understand) → ✋ 操作 (act)
```

「見て・気づき・動かす」という巡礼者の体験そのものをゲーム化している。

---

## 総括

> **「八百万の神々が宿る現実の場所を巡礼者が訪れ、AIの神と対話しながら "その場の価値を増やし課題を解決する" 営みを通じて、徳を積み、ひいては現実世界そのものを幸福にしていく」**

ゲーミフィケーションされた地域活性化・コミュニティ貢献の仕組みである。技術的には、AIで「場の人格」を生成し、現実の巡礼行為とUGC（写真・レビュー・課題解決）を徳の経済に接続している点が独自性となっている。
