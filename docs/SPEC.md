# Yaorozu Quest（八百万クエスト）仕様書

> 街歩きを「八百万の神々との出会い」に変える、位置情報型の巡礼・探索アプリ。
> 東京・新中野を起点に、豆知識クイズと神様との会話を通じて、街をより深く・楽しく知る体験を提供する。

- 文書バージョン: 1.0
- 最終更新: 2026-06-08
- 対象: 企画 / デザイン / 開発

---

## 1. コンセプト

| 項目 | 内容 |
| --- | --- |
| ビジョン | 「散歩したくなる」「街に詳しくなれる」体験を、ゲーミフィケーションで実現する |
| 世界観 | あらゆる場所に八百万（やおろず）の神が宿る。神々が巡礼者（ユーザー）に呼びかけ、土地の謎を出題する |
| コアバリュー | ①現地に行く動機づけ ②土地の豆知識・歴史の学習 ③神様キャラとの対話による没入感 |
| 通貨 | 「徳（Toku）」ポイント。クイズ正解・口コミ投稿などで獲得し、レベルと称号に反映される |

## 4. クイズ巡礼システム（新中野シリーズ）

`src/data/shinnakano-quiz.ts` に7問を定義。新中野駅〜鍋屋横丁〜青梅街道〜桃園川緑道を舞台とする。

### 4.1 位置ゲート
- 各クイズには緯度経度が紐づく。現在地から **300m（`QUIZ_UNLOCK_RADIUS_KM = 0.3`）以内** に近づくと解放。
- 未解放のクイズは「現地に近づくと解放（あと Xm）」と表示し、問題文は隠す。
- デモ用に「ワープ」ボタンで擬似的に現地へ移動可能。

### 4.2 神様からの呼びかけ
- 解放された瞬間、神（ナベ爺など）が period 調のセリフで召喚（`call` フィールド）。
- 例:「よう来たな、旅の者よ。この横丁の名が、なぜ『鍋屋』と呼ばれるか…そなたは知っておるか？」

### 4.3 動的御利益（オッズ）システム
全プレイヤーの正答率に応じて獲得徳が変動する。

```
獲得徳 = baseToku × オッズ
オッズ = clamp( ODDS_K / (正答率 + ODDS_EPS), ODDS_MIN, ODDS_MAX )
```

| パラメータ | 値 | 意味 |
| --- | --- | --- |
| `ODDS_K` | 0.5 | 基準係数 |
| `ODDS_EPS` | 0.1 | ゼロ除算回避 |
| `ODDS_MIN` / `ODDS_MAX` | 0.5 / 5.0 | 倍率の下限・上限 |
| `MIN_SAMPLE` | 30 | これ未満の挑戦数は仮オッズ `1.5` 固定 |

- **狙い**: みんなが解けない難問ほど高倍率（最大5倍）。易問は0.5倍に抑え、簡単な問題の周回（ファーミング）を防ぐ。
- 難易度バッジ: 正答率に応じて「秘/難/並/易/集計中」を表示。

### 4.4 シリーズ制覇
- 7問すべて回答で「新中野クイズ巡礼」制覇バッジ（⛩️）を獲得。
- 回答状況・制覇状態は localStorage に永続化。

## 4.5 神様からの依頼（タスク）

各スポットに宿る神は、巡礼者にタスクを依頼する。**地図上では神が吹き出しで呼びかけ（swarm 表示）**、近づかなくても「この地の神が何を求めているか」が一目で分かる。タスクは詳細ページで実行でき、達成すると徳を授かる。

### 4.5.1 タスク種別カタログ（`src/data/god-tasks.ts`）

| 種別 | アイコン | 内容 | 既定報酬 | 付与カテゴリ |
| --- | --- | --- | --- | --- |
| `photo` | 📸 | 佳き一枚を奉納（写真投稿） | +30徳 | 全スポット共通 |
| `event` | 🎏 | 今のできごとを共有 | +20徳 | 全スポット共通 |
| `review` | 🗣️ | 口コミを言伝て | +50徳 | 全スポット共通 |
| `sns` | 📣 | SNSで広める | +15徳 | 全スポット共通 |
| `buy` | 🛍️ | モノを買ったと伝える | +40徳 | 商業施設 |
| `eat` | 🍜 | 食べた感想を伝える | +40徳 | 飲食店・商店街 |
| `cleaning` | 🧹 | 掃除の行き届きを確認 | +25徳 | 寺院・神社・公園 |

- **共通4種**（photo / event / review / sns）はすべてのスポットに付与。
- **カテゴリ別タスク**はスポットの `category` に応じて自動追加。
  - 商業施設 → 買物報告（`buy`）
  - 飲食店・商店街 → 実食の声（`eat`）
  - 寺院・神社・公園 → 清掃確認（`cleaning`）
- 各タスクの依頼セリフは土地名を織り込んで動的生成（例：「鈴森公園の佳き景色を一枚、撮って奉納してはくれぬか。」）。

### 4.5.2 地図 swarm 呼びかけ
- 地図上の各マーカー上部に、神の依頼が浮遊する吹き出しで表示される。
- スポットごとに異なるタスクを出し、浮遊アニメをずらすことで、地図全体が swarm のように賑わう。
- アクティブなスポットは赤系、その他は白系の吹き出しで強調。

### 4.5.3 管理画面での設定
- 管理コンソールのスポット編集で、**神が依頼できるタスク種別をトグルで設定**できる。
- 未設定ならカテゴリ標準（共通＋カテゴリ別）を使用。設定するとそのスポット専用に上書き（`spot.taskTypes`）。

## 4.6 UGCによる神の成長

神は巡礼者の貢献（UGC）によって育っていく。

- **写真**: スポットの写真は **初期は未設定（空）**。ユーザーが写真タスクで投稿すると、その写真がスポットのメイン写真にセットされる。複数枚の投稿で「みんなの写真」ギャラリーが充実していく。
- **写真モデレーション**: 不適切な写真は、誰でも 🗑 ボタンで **却下（削除）** できる（コミュニティ・モデレーション）。メイン写真が却下された場合は次の投稿写真へ自動で差し替わる。
- **楽しみ方**: 口コミ・実食・できごと等のタスク達成で「ここでの楽しみ方」が増えていく（`db.addEnjoyment`）。
- 関連メソッド: `db.addSpotPhoto` / `db.rejectSpotPhoto` / `db.getSpotPhotos` / `db.getPrimaryPhoto` / `db.addEnjoyment` / `db.completeGodTask`。

## 4.7 地図演出・スポット規模・ランキング

- **東京1000スポット**: 東京全域の主要エリアを中心に、神社・寺院・公園・商店街・商業施設・飲食店を手続き生成（`src/data/tokyo-spots.ts`、約1000件）。
- **1画面の表示数コントロール**: 地図はビューポート内の近い順に、**ズーム連動の上限**（広域12件〜拡大60件）で間引いて描画（`maxMarkersForZoom`）。
- **徳フキダシ（サウナイキタイ風）**: 各ピンは「徳 1,234」を示す青いフキダシ＋神アイコン。**地名はフキダシではなく縁取り文字**（白フチ）で地図ラベル風に表示。各スポットの徳総量は `db.getSpotToku`（シード人気値＋貢献徳＋UGC徳）。
- **選択の挙動**: マーカー選択で ①フキダシが**反転**（青⇔白）②地図**中央へパン** ③下部オーバーレイパネルが切り替わる。
- **下部オーバーレイ（心の声）**: 選択スポットの神アイコン・名称・徳・距離・創世主を表示。**神の心の声**を**一文字ずつ**（ユーザーに語りかける口調で）表示し、複数タスクを交互に。**タップで詳細ページへ**。
- **波紋エフェクト**: ピンから青い波紋がふわっと広がり、神の存在感を示す。
- **現在地と方角**: 現在地マーカーは青ドット＋方角コーン（選択スポット方向を指す）＋「現在地」ラベル。右下に現在地へ戻るボタン。
- **徳の石碑（スポット別ランキング）**: 詳細ページに、そのスポットで最も徳を積んだ巡礼者 上位5名を石碑のように掲示（`db.getSpotRanking`）。1位には王冠、各人は神アイコンで表示。
- **神のつぶやき（詳細ページ）**: 詳細ページ上部に、神がSNSでつぶやくようなカードを表示し、依頼セリフを一定間隔で切り替える。
- **UGCいいね→徳**: 詳細ページの口コミに「いいね」ボタン。押すと投稿者に +10徳（`db.likeUgcPost`）。
- **アクセントカラー**: 全体のアクセントは青（`--color-shrine-red` を青に再定義）。地図のフキダシ・現在地・選択も青。
- **カテゴリフィルタ**: 地図上部に すべて/神社/寺院/公園/商店街/商業施設/飲食店 のフィルタ。
- **最寄りのみフキダシ**: フキダシ（徳）は**最も近い神＋選択中**のみ表示。他は小ピン＋地名のみ（混雑回避）。
- **この場所で再検索**: 地図をドラッグすると上部に表示。押すと地図中央に最も近いスポットを選択。
- **拡大縮小ボタン非表示**（ピンチ/ホイールで操作）。
- **徳の石碑タブ**: 詳細ページは 詳細／徳の石碑／会話 の3タブ。石碑は 全期間/月間/週間 のサブタブ。
- **神のつぶやき**: まず場所紹介→みどころ→要望の順で回転。文字数で画面が動かないよう固定高さ。
- **管理画面パスワード**: `Kaseijinbiz1`（`ADMIN_PASSWORD`）。

> バッジ・称号・貢献度・神アイコンの詳細は **[BADGES.md](./BADGES.md)** を参照。

## 5. スポット詳細ページ（写真 ＋ 神様との会話）

マップのマーカー／スポットカードをタップで全画面オーバーレイを開く（`src/components/SpotDetail.tsx`）。

### 5.1 構成
1. **ヒーロー写真**: スポット写真をフルワイドで表示。未投稿なら「まだ写真がありません」プレースホルダ。カテゴリ・名称・座標をオーバーレイ。
2. **タブ切替**: 「詳細」／「〈神様名〉と会話」。
3. **詳細タブ**:
   - 説明文
   - **神様からの依頼**（タスク一覧・実行ボタン・報酬）→ §4.5
   - **みんなの写真**（投稿ギャラリー・投稿ボタン・🗑却下）→ §4.6
   - この地に宿る神カード（話す）
   - ここでの楽しみ方（UGCで増える）
   - 属性タグ / 巡礼者の口コミ
   - **関連するスポット**（同カテゴリ優先で他スポットへリンク）
4. **会話タブ**: チャットUI。プリセット質問（歴史／見どころ／近くのおすすめ）と自由入力。

### 5.2 会話エージェントの解決
- スポットに個別Agent（`db.getAgentBySpot`）が登録されていればそれを使用。
- 無ければ `spot.godName` / `godEmoji` から**合成エージェント**（`agent-synthetic-<spotId>`）を生成。

### 5.3 チャットAPI（`/api/chat`）
- `OPENAI_API_KEY` があれば OpenAI（`gpt-4o-mini`）でペルソナ応答。UGCをRAG文脈、アフィリエイトを推薦候補として注入。
- キーが無い／エラー時は**ルールベースのフォールバック**へ自動切替。
  - 合成エージェント＋スポット情報がある場合は、**そのスポットの説明・楽しみ方・口コミ**を使った土地固有の応答を返す（`getSpotFallbackResponse`）。
- 返答は150文字以内、キャラクター口調を維持。

## 7. UGC・創世主（クリエイター）システム

| 概念 | 内容 |
| --- | --- |
| 口コミ（UGC） | スポットへの投稿。投稿で +50徳、いいね獲得で著者に +10徳 |

## 11. 距離計算

緯度経度間の距離は **Haversine 公式**（地球半径 R = 6371km）で算出。
- クイズ解放判定（300m）
- 「近くのクエスト」の距離順ソート
- スポットの接近判定（1.0km 以内で AR/会話を有効化）
