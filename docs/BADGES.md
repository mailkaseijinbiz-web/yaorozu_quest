# Yaorozu Quest バッジ・称号 仕様書

> 巡礼者の貢献（訪問・ミッション達成・フォロワー・累積徳）に応じて、
> バッジと称号が授与される。これらは「街を歩き、神に尽くす」動機づけの中核。

- 文書バージョン: 1.0
- 最終更新: 2026-06-08
- 関連実装: `src/data/badges.ts` / `src/data/levels.ts` / `src/lib/db.ts`（`UserContribution`）

---

## 1. 称号の二系統

称号は **2つの軸** で構成される。

| 系統 | 由来 | 例 | 実装 |
| --- | --- | --- | --- |
| **レベル称号** | 累積徳（totalToku）で昇格 | 見習い巡礼者 → 八百万の大神 | `levels.ts` |
| **名誉称号** | 特定ミッションの達成回数・フォロワー等 | フォトグラファー / メンテナー | `badges.ts` |

プロフィールには「現在のレベル称号」＋「獲得した名誉称号」が並んで表示される。

| 称号 | アイコン | 条件 |
| --- | --- | --- |
| フォトグラファー | 📷 | 写真ミッション 10回 |
| 名フォトグラファー | 🎞️ | 写真ミッション 50回 |
| メンテナー | 🧹 | 点検（清掃）ミッション 10回 |
| 街の守り手 | 🛡️ | 点検ミッション 50回 |

| 美食の使徒 | 🍜 | 実食の声 10回 |

## 5. 貢献度の記録（データモデル）

`UserContribution`（`src/lib/db.ts`、localStorage `yaorozu_user_stats`）

| フィールド | 内容 | 加算タイミング |
| --- | --- | --- |
| `visitedSpotIds[]` | 訪れたスポットID | 詳細ページを開いた時（+5徳） |
| `taskCounts{type}` | タスク種別ごとの達成回数 | 神の依頼タスク達成時 |
| `spotContrib{spotId}` | スポット別の貢献徳 | タスク/写真/訪問時（石碑ランキング用） |
| `followers` / `following` | フォロー関係 | デモ用（初期値あり） |

主なメソッド: `recordVisit` / `recordTaskDone` / `adjustFollow` / `getSpotRanking`。

## 6. アカウントアイコン（神にちなんだ）

- ユーザーアイコンは写真ではなく、**神にちなんだ絵文字**（⛩️🦊🐉🙏🌊🌲🪷🔥🌸🦌🍶🏮）。
- ユーザーIDから決定論的に割り当てる（`godAvatarEmoji`）。
- フレーム色はレベル称号に連動。

---

## 7. 石碑ランキング（スポット別）

- 各スポット詳細ページに「徳の石碑」を表示。
- そのスポットで最も徳を積んだ巡礼者 上位5名を、石碑に刻むように掲示（`getSpotRanking`）。
- 集計＝UGC投稿による徳 ＋ タスク/写真/訪問による貢献徳（`spotContrib`）。
- 1位には王冠 👑、各人は神アイコンで表示。
